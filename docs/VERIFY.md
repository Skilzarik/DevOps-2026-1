# Что делает `make verify`

`make verify` - единственная команда, которой подчиняется любое изменение. Она выполняет по очереди четыре проверки
и останавливается на первой ошибке. Код возврата ненулевой, если хоть одна проверка не пройдена.

| Шаг | Команда | Что проверяет | Что ловит |
|---|---|---|---|
| 1 | `make policy` | `scripts/check_policy.py` | пропущенные и удалённые тесты, сниженные пороги, исключения анализаторов без обоснования, пароли и `.env` в git, зависимости без точных версий, ссылки на несуществующие тесты в `docs/TRACEABILITY.md`, долю требований ТЗ ниже 40% |
| 2 | `make quality` | `ruff check` и `ruff format --check` | ошибки стиля, неиспользуемые импорты, типичные баги (bugbear), порядок импортов, форматирование |
| 3 | `make sast` | `bandit -r app ale` | небезопасные конструкции: захардкоженные секреты, слабая криптография, привязка ко всем интерфейсам, небезопасная десериализация |
| 4 | `make test` | `pytest` с покрытием | логику приложения (unit), работу с PostgreSQL (интеграционные), миграции на чистой и заполненной БД, резервную копию и восстановление; порог покрытия `fail_under` |

Отчёты после прогона: `backend/reports/junit.xml` (результаты тестов), `coverage.xml` и `htmlcov/` (покрытие), `bandit.json` (SAST).

Отдельно (в `verify` не входят, потому что долгие или нужны по запросу):

| Команда | Назначение |
|---|---|
| `make mutate` | вносит в код по одной ошибке (15 мутантов) и проверяет, что тесты падают |
| `make migrate-check` | только проверки миграций |
| `make test-unit` | только unit-тесты без базы данных, секунды |
| `make backup` и `make restore FILE=...` | резервная копия и восстановление рабочей БД |

## Изоляция тестов

Интеграционные тесты работают только с базой из `TEST_DATABASE_URL` (файл `backend/.env.test`).
Имя базы обязано оканчиваться на `_test`, иначе тесты не стартуют. Схема создаётся миграциями,
перед каждым тестом таблицы очищаются.

## Контрольное изменение

1. Создайте ветку и задачу.
2. Измените поведение (сначала тест, который падает, затем код).
3. `make verify` должен стать зелёным, результат прикладывается к Pull Request.
